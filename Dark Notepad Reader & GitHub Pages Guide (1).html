💡 Pourquoi utiliser GitHub Pages ?

                    
En hébergeant gratuitement cette page sur GitHub, vous pouvez modifier votre texte **directement dans votre navigateur** sur le site de GitHub. Le site se mettra à jour automatiquement en quelques secondes, sans avoir besoin de retélécharger ou réimporter le fichier HTML sur votre ordinateur !

                


                

                    

                        1
                        

                            
Créer un compte GitHub & un dépôt

                            
Rendez-vous sur github.com, créez un compte gratuit, puis cliquez sur le bouton vert **"New"** (ou **"Repository"**).

                        

                    


                    

                        2
                        

                            
Nommer le dépôt & Ajouter le fichier index.html

                            
Nommez le dépôt (ex: mon-bloc-note), cochez **"Public"**, puis créez le dépôt. Cliquez ensuite sur **"Creating a new file"**, nommez le fichier index.html et collez-y tout ce code HTML.

                        

                    


                    

                        3
                        

                            
Activer GitHub Pages

                            
Dans votre dépôt, allez dans **Settings** ➔ **Pages**. Sous *Build and deployment*, choisissez la branche **Main** et cliquez sur **Save**. Votre site aura une adresse web unique disponible partout !

                        

                    


                    

                        4
                        

                            
Comment modifier le texte directement dans le code ?

                            
Ouvrez le fichier index.html sur GitHub, cliquez sur l'icône de crayon ✏️ (Edit), et modifiez la variable defaultNoteText vers la ligne 210. Cliquez ensuite sur **"Commit changes..."** : votre site est instantanément mis à jour !
